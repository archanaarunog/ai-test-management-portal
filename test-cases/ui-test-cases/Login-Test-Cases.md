# Login – UI Test Cases

## Test Case Plan

This test suite validates the Login module of the AI Test Management Portal, covering UI elements, successful and unsuccessful authentication, field validations, password visibility, Remember Me, Forgot Password, security inputs, and keyboard accessibility.

**Total Test Cases:** 23

| Test Scenario | Test Steps | Expected Result |
|---|---|---|
| **LOGIN-001 – Verify Login Page UI** | 1. Navigate to the Login page.<br>2. Verify the **AI Test Management Portal** branding.<br>3. Verify the left-side content section.<br>4. Verify the **Sign in to your account** section.<br>5. Verify Email and Password fields.<br>6. Verify Remember Me checkbox.<br>7. Verify Sign In button.<br>8. Verify Forgot Password link.<br>9. Verify password visibility icon. | Login page is displayed with the expected branding, content, login fields, Remember Me, Sign In, Forgot Password and password visibility controls. |
| **LOGIN-002 – Login with valid credentials** | 1. Navigate to the Login page.<br>2. Enter valid email address.<br>3. Enter valid password.<br>4. Click **Sign in**. | Login is successful. **"Welcome back! Login successful."** message is displayed and the user is navigated to the Dashboard. |
| **LOGIN-003 – Login with invalid email** | 1. Enter an invalid/unregistered email address.<br>2. Enter a valid password.<br>3. Click **Sign in**. | Login fails. **"Invalid email or password. Try the demo credentials shown below."** error is displayed. User remains on the Login page. |
| **LOGIN-004 – Login with invalid password** | 1. Enter a valid email address.<br>2. Enter an incorrect password.<br>3. Click **Sign in**. | Login fails and the invalid credentials error is displayed. User remains on the Login page. |
| **LOGIN-005 – Login with invalid email and password** | 1. Enter an invalid email address.<br>2. Enter an incorrect password.<br>3. Click **Sign in**. | Login fails and the invalid credentials error is displayed. User is not authenticated. |
| **LOGIN-006 – Validate special characters in email** | 1. Enter an invalid email containing special characters, e.g. `test@#$`.<br>2. Enter a password.<br>3. Click **Sign in**. | Email validation is triggered and **"Enter a valid email address"** is displayed. Login is not submitted. |
| **LOGIN-007 – Verify SQL injection input** | 1. Enter `' OR '1'='1` in the Email field.<br>2. Enter `' OR '1'='1` in the Password field.<br>3. Click **Sign in**. | Authentication is not bypassed. User is not logged in and the invalid input is rejected. |
| **LOGIN-008 – Login with empty email** | 1. Leave the Email field empty.<br>2. Enter a valid password.<br>3. Click **Sign in**. | **"Email is required"** validation message is displayed. Login is not submitted. |
| **LOGIN-009 – Login with empty password** | 1. Enter a valid email address.<br>2. Leave the Password field empty.<br>3. Click **Sign in**. | **"Password is required"** validation message is displayed. Login is not submitted. |
| **LOGIN-010 – Login with both fields empty** | 1. Leave Email empty.<br>2. Leave Password empty.<br>3. Click **Sign in**. | **"Email is required"** and **"Password is required"** validation messages are displayed. Login is not submitted. |
| **LOGIN-011 – Verify password masking** | 1. Click the Password field.<br>2. Enter a password.<br>3. Observe the Password field. | Password characters are masked and are not displayed as plain text. |
| **LOGIN-012 – Verify show/hide password** | 1. Enter a password.<br>2. Verify that the password is masked.<br>3. Click the eye icon.<br>4. Observe the Password field.<br>5. Click the eye icon again. | Password becomes visible when the eye icon is clicked and becomes masked again when the icon is clicked a second time. |
| **LOGIN-013 – Validate email format** | 1. Enter an invalid email such as `test`.<br>2. Enter a password.<br>3. Click **Sign in**.<br>4. Repeat using other invalid formats such as `test@`, `@test.com` and `test.com`. | **"Enter a valid email address"** validation message is displayed for invalid email formats. Login is not submitted. |
| **LOGIN-014 – Login with uppercase email** | 1. Enter the valid email address using uppercase characters.<br>2. Enter the correct password.<br>3. Click **Sign in**. | Email is normalized and login succeeds. User is navigated to the Dashboard. |
| **LOGIN-015 – Verify password case sensitivity** | 1. Enter the valid email address.<br>2. Enter the correct password with incorrect letter casing.<br>3. Click **Sign in**. | Login fails because the password is case-sensitive. Invalid credentials error is displayed. |
| **LOGIN-016 – Login with leading/trailing spaces in email** | 1. Enter the valid email address with leading spaces.<br>2. Enter the correct password.<br>3. Click **Sign in**.<br>4. Repeat with trailing spaces. | Email spaces are trimmed before authentication and login succeeds. User is navigated to the Dashboard. |
| **LOGIN-017 – Verify Remember Me functionality** | 1. Enter valid credentials.<br>2. Select **Remember me**.<br>3. Click **Sign in**.<br>4. Reload/reopen the application.<br>5. Observe the authentication state. | Remember Me functionality preserves the authentication state and the user remains authenticated after reopening/reloading the application. |
| **LOGIN-018 – Verify Sign In button during authentication** | 1. Enter valid credentials.<br>2. Click **Sign in**.<br>3. Observe the Sign In button while authentication is in progress. | Button changes from **"Sign in"** to **"Signing in..."** and is disabled while authentication is being processed. |
| **LOGIN-019 – Forgot Password with valid email** | 1. Click **Forgot password?**.<br>2. Verify the Reset Password dialog.<br>3. Enter a valid email address.<br>4. Click **Send reset link**. | Reset Password dialog is displayed. A message indicates that if an account exists, a reset link has been sent. **"Password reset link sent (simulated)."** informational toast is displayed. |
| **LOGIN-020 – Forgot Password with invalid email** | 1. Click **Forgot password?**.<br>2. Enter an invalid email address.<br>3. Click **Send reset link**. | **"Enter a valid email address"** validation message is displayed. Reset request is not processed. |
| **LOGIN-021 – Forgot Password with empty email** | 1. Click **Forgot password?**.<br>2. Leave the email field empty.<br>3. Click **Send reset link**. | Email validation is triggered and **"Enter a valid email address"** is displayed. |
| **LOGIN-022 – Forgot Password with unknown email** | 1. Click **Forgot password?**.<br>2. Enter a syntactically valid but unregistered email address.<br>3. Click **Send reset link**. | Application displays a generic reset message without revealing whether the email is registered. Informational reset-link toast is displayed. |
| **LOGIN-023 – Verify keyboard/tab navigation** | 1. Navigate to the Login page.<br>2. Use the **Tab** key to move between controls.<br>3. Verify focus moves through the interactive elements.<br>4. Enter credentials using the keyboard.<br>5. Submit the login form using the keyboard. | Interactive Login page controls can be accessed using keyboard navigation and the login flow can be completed without requiring mouse interaction. |
